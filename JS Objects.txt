Shallow Copy vs Deep Copy
A shallow copy creates a new top-level object but keeps references to nested objects, so modifying a nested object can affect the original. A deep copy recursively creates independent copies of nested objects, so changes to the copy don't affect the original.
const original = {
  name: "Alice",
  address: {
    city: "Hyderabad"
  }
};

const shallow = { ...original };
const deep = structuredClone(original);

shallow.address.city = "Delhi";

console.log(original.address.city); // Delhi

deep.address.city = "Mumbai";

console.log(original.address.city); // Delhi
Object De-structuring?
Object destructuring is a JavaScript syntax that lets you extract properties from an object and store them in variables easily.
const user = {
  name: "Alice",
  age: 25,
  city: "Hyderabad"
};

const { name, age, city } = user;

*For modifying-
user.age = 29; => If the property exists it will modify it or else create a new one

*For deleting-
delete user.age => deletes the property and not the Parent object

* IN Operator
in operator is used to check whether a property exists in the given object or its prototype
console.log("age" in user);
=> in also checks inherited properties.

* hasOwn()
Object.hasOwn(user,"age");
Checks whether a property exists directly on the object.It does not look through the prototype chain.

*hasOwnProperty()
user.hasOwnProperty("age");
checks whether a property exists in an object. hasOwnProperty() itself can be overridden or unavailable.

*Object.keys() => Return all the own keys of an object

*Object.values() => Return the value of own keys.

* Object.entries() => Returns array where each element is an array of form [key, value]

* Object.fromEntries() => Convert [key,value] array to object

*Object.assign(target,source) => Copies properties from source object to target object. Performs shallow copy returns an object that can be stored in a variable

* Object.create(prototype) => Create a new project from prototype. The new object will not have its own property unless created. It will return the properties of prototype. Nested properties are shared between the new object and the prototype

* Object.freeze() => Makes object non modifiable at the top level. Nested properties can still be changed

* Object.seal() => Values can be modified but not added.
